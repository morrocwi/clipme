# Skill: production-orchestrator

## Purpose
Compile an idea/source package into one finished audiovisual master by invoking the other clipme skills in dependency order.

## Inputs
- project brief or raw idea
- source material
- target duration/profile
- language/audience
- delivery format
- available tools/providers
- constraints: budget, time, rights, brand, safety

## Outputs
- project contract
- production plan
- locked creative bibles
- work packets for subordinate skills
- sequence/reel masters
- final master
- QC report
- reproducibility manifest

## Procedure
1. Select a duration profile.
2. Normalize the brief into project.yaml.
3. Build fact ledger for factual work.
4. Invoke story.
5. Invoke director.
6. Invoke storyboard/previs.
7. Invoke cinematography/art/motion planning as needed.
8. Invoke sound planning and narration workflow.
9. Compile exact shot/timeline contracts.
10. Produce assets.
11. Render bounded units.
12. Invoke editor.
13. Invoke continuity and QC.
14. Repair failures.
15. Assemble and finish one master.

## Scale rule
- <=90s: direct beat/shot compilation allowed.
- >90s to ~10m: scene compilation.
- ~10–60m: sequence compilation.
- >60m / feature: act→sequence→scene compilation with progressive locks.

## Gate
Never mark complete while any blocking QC ticket is unresolved.
