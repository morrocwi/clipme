# Skill: accessibility-delivery

## Purpose
Prepare the approved master for real-world viewing and distribution.

## Inputs
- final master
- transcript
- target platform/spec
- language requirements
- accessibility requirements

## Outputs
- captions/subtitles
- subtitle timing/QC
- optional audio-description plan
- alternate aspect-ratio versions
- platform encodes
- thumbnails/poster frames where requested
- delivery manifest
- checksum/hash

## Checks
- subtitle text accuracy
- subtitle reading speed and timing
- safe areas
- text contrast
- language tags
- audio channel layout
- codec/container
- resolution/fps
- loudness target when specified
- duration
- checksum

## Gate
Do not label a deliverable as platform-ready until it passes the actual target specification.
