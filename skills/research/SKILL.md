# Skill: research-fact

## Purpose
Create a traceable evidence layer for any factual, documentary, educational, scientific, historical, journalistic, or data-driven production.

## Outputs
- fact_ledger.json
- source register
- quote register
- uncertainty notes
- claims-to-script mapping
- visual-evidence notes

## Fact record
Each material claim should record:
- fact_id
- claim
- source
- source date/version
- evidence location
- confidence/status
- exact number/name/date spelling
- allowed paraphrase
- visual representation constraints
- script/scene references

## Rules
- separate sourced facts from inference and dramatization
- never fabricate citations
- preserve units and denominators
- record uncertainty/disagreement
- recheck time-sensitive claims near delivery

## Gate
Blocking if a material factual claim has no support or contradicts the approved source package.
