# Skill: color-finishing

## Purpose
Normalize and intentionally shape the final image while preserving continuity, skin/material plausibility, text readability, and delivery safety.

## Inputs
- approved edit
- visual bible
- shot/scene intent
- display/delivery target

## Outputs
- normalization notes
- scene matching
- look application
- shot fixes
- legal/safe output checks as required
- final graded master or grade instructions

## Order
1. technical normalization
2. exposure/white-balance consistency
3. shot matching
4. look
5. local corrections
6. graphics/readability check
7. delivery check

## Synthetic footage
Pay special attention to:
- inconsistent white balance
- skin/material drift
- impossible highlight/shadow response
- adjacent-shot saturation mismatch
- AI-generated texture flicker

## Gate
Fail when the grade obscures required information or creates visible continuity errors.
