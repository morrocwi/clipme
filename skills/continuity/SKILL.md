# Skill: continuity

## Purpose
Maintain stable world, character, object, language, factual, spatial, and temporal state across independently generated units.

## Inputs
- continuity bible
- world/character/visual bibles
- shot contracts
- rendered frames/clips
- script/dialogue
- asset manifest

## Outputs
- continuity state after each scene/sequence
- contradiction report
- screen-direction report
- terminology/number consistency report
- repair tickets

## Track
- character appearance and age/state
- wardrobe
- injuries/physical changes
- props and ownership
- object position
- location geography
- entry/exit direction
- eye/gaze direction
- time/day/date/weather
- lighting direction
- vehicles/devices
- typography/brand elements
- factual values
- names/pronunciation/terminology

## Gate
Blocking contradictions must be repaired before feature-wide final assembly.
